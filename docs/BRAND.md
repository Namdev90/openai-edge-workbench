# Namu AI Workbench visual identity

The Workbench is a local instrument console: midnight-blue anodized panels, recessed displays, quiet orbital traces and clear physical controls. The repository and dashboard share this identity. Decoration supports the controls and evidence; it never implies that an unverified operation passed.

## Name and mark

Use **Namu AI Workbench** in product headings and interface copy. **Namu AI** is the short form. Historical OpenAI Edge Workbench launcher names and installation paths remain for compatibility. The project is an independent community utility, separate from AMReye.AI and not an OpenAI product.

The original **N mark** is one continuous path: rise, cross diagonally, rise. Use rounded joins and a cyan-to-violet signal stroke inside a recessed square or circular instrument. Grid lines and concentric orbital traces belong in surrounding space; they should not compete with the name or controls.

## Shared palette

| Role | Color | Use |
| --- | --- | --- |
| Background | `#070B18` | Workspace and deepest display recesses |
| Surface | `#0E1730` | Panels and cards |
| Raised surface | `#172544` | Anodized edges, housings and dividers |
| Cyan | `#6EE7FF` | Primary controls, focus and signal traces |
| Violet | `#AD92FF` | Secondary accents and orbital traces |
| Ink | `#E8EEFF` | Headings and primary content |
| Muted | `#A7B4D4` | Supporting copy and labels |
| Warning | `#FFD18A` | Review needs and caution |
| Error | `#FF95AA` | Failures and invalid actions |
| Success | `#86EFCA` | A specific successful recorded check |

Use ink or muted text on the dark surfaces. Keep accent glows and grid traces subtle. Statuses always need readable text in addition to color, and focus must remain visible. Reduced motion removes decorative movement rather than information.

## Typography and composition

Use a system sans-serif stack led by Segoe UI for interface text, with a system monospace stack for command lines, versions and recorded output. Product headings have generous space and restrained weight; small instrument labels may use uppercase and modest letter spacing. Avoid long paragraphs in uppercase or monospace.

On the repository front page, show the setup command before deep documentation, then the actual interface, capability groups and evidence boundaries. Collapse technical detail when it improves scanning. Original SVG artwork stays self-contained: no scripts, external images, remote fonts or runtime dependencies.

## Honest presentation

- Label every simulated screenshot and report. Screenshots demonstrate the interface, not a successful installation.
- Keep 100 implemented Feature Studio actions distinct from the separate 100-item roadmap and from the number of software installers.
- Describe a verification status at the level of the recorded check. Keep warnings, failures and unavailable channels visible.
- Present cloud AI as optional, consent-based advice with provider limits. Built-in guidance remains local and rule-based.
- Describe the 836-language atlas as an isolated metadata-fixture experiment, not application implementations in those languages.
