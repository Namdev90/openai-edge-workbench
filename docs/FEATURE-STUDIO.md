# Feature Studio

Search 100 actions by name, description or `f` ID; filter categories, save favorites, or press **Ctrl+K** / **Cmd+K** for the keyboard palette. Arrow keys choose an action, Enter runs it and Escape restores focus.

## Before installation

The visible 12-second automatic start pauses when you change a selection or interact with Feature Studio. Ten profiles offer different optional pack selections. Run a profile, inspect its plan, then press **Apply installation selection**. Apply changes checkboxes and never starts installation. Core tools remain included; press **Start now** when ready.

**Full workshop without model requests** selects every optional pack except the live model check. **Full workshop with connection test** includes one quota-consuming request and labels that effect. Profiles do not purchase software, create credentials or grant cloud permissions.

## Inspect and compare

Diagnostics read environment facts or run fixed read-only checks. Official catalog actions contact their publishers only when requested. Failed or unavailable evidence remains visible; a missing tool never triggers an implicit installation.

Report analysis selects the latest completed diagnostic by default. Use **Report to inspect** for another run. Up to 60 completed reports are listed; partial reports are excluded. Analyses explain failures, warnings, compatibility, retained originals, migration, quotas and verification limits. Comparisons use the selected run and its predecessor; differing selections can produce different operation sets.

## Save locally

- JSON preserves structured evidence; Markdown and HTML summarize it.
- CSV neutralizes spreadsheet formula prefixes. HTML escapes report content.
- A support ZIP contains only `Diagnostic.json`, `Review.md` and `SHA256SUMS.txt` for the selected sanitized report. Authentication/session files and private backups are excluded.
- Save/load/remove handle one local recipe with eight validated boolean options. Unknown files and unowned directories are preserved. Recipe writes wait for installation to finish.

Downloads stay local until you share them. Review redaction first. No feature analysis makes a model request or uploads a support ticket.

## Preferences and activity

Favorites, density, text size and reduced motion stay in this browser. Denied browser storage still permits operation. Log filters change display only, not saved evidence. Feature job history covers this server session, separately from completed installation reports.

The server permits two concurrent jobs and retains 30 results. The browser polls up to three minutes; a UI timeout does not cancel or certify the query. Simulation skips native diagnostic commands and network checks and never represents laptop verification.
