# Documentation guide

Choose a guide for the task in front of you. The public project is **Namu AI Workbench**; repository, launcher and installation-path names retain `openai-edge-workbench` for compatibility.

## How to read the evidence

A passing automated test, a simulated dashboard, an actual Windows install, an authenticated account and a successful model request are separate claims. Use the dated verification record for its exact scope; consult your own current report for current installed versions and outcomes. Provider catalogs, preview channels, billing terms and account access can change.
