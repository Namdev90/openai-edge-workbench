# Namu AI Workbench design context

The local Windows dashboard uses semantic HTML, original CSS and JavaScript, served by Python. The user selected a hyperrealistic skeuomorphic instrument-console direction on 10 October 2026.

Midnight-blue anodized metal panels, bevels, recessed readouts, visible fasteners and raised buttons share a consistent overhead light source. Electric cyan marks primary controls, violet adds secondary illumination, and amber marks attention. Status labels and numbers always come from real engine state. Decorative hardware conveys no invented telemetry.

Reuse native inputs, buttons, progress, tables and the existing command dialog. Preserve keyboard focus, generous targets, readable text, high-contrast modes, reduced motion and narrow layouts. Text and layout preferences continue to work. All textures are CSS; the dashboard needs no external design assets or font requests.

21st catalog search supplied visual reference leads for skeuomorphic switches and tactile buttons. No component code was retrieved or incorporated; the existing project primitives avoid a framework migration. Durable constraints and the search references are recorded in design.json.
